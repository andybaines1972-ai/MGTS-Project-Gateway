# MGTS Project Gateway

Single-page app for BTEC HNC Unit 4004 (Managing a Professional Engineering Project): idea generator, go/no-go gateway, AI/IoT layer guide, criteria map and a copyable project summary.

## Updating each year
Edit the `CONFIG` block and the `IDEAS` list at the top of the `<script>` in `index.html` when Pearson releases the new theme. The unit criteria, gateway logic and IoT stack content stay the same.

## Hosting
Static site, no build step. Deployed on Vercel. Learner answers are kept in each browser's local storage only.
